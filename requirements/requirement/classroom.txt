# LittleSprouts — Complete Classroom Requirements

## Objective

Implement a complete Classroom management and configuration feature for LittleSprouts.

A classroom is more than a physical room.

A classroom represents:

* Physical room
* Age group
* Capacity
* Children
* Teachers
* Teacher assignments
* Schedule
* Operating hours
* Classroom type
* Learning environment
* Activities
* Equipment and resources
* Safety information
* Ratios
* Daily routines
* Classroom rules
* Emergency information
* Classroom preferences
* Classroom communication
* Classroom history
* Classroom growth / living world

Do NOT create one large Classroom table containing every field.

Separate classroom identity, physical information, staffing, children, schedules, safety, resources, activities and configuration.

# 43. Multi-Tenant Requirements

Every classroom belongs to:

Tenant
→ Branch
→ Classroom

A user must never access another tenant's classrooms.

Enforce tenant isolation at the application/service/data access layer.

Do not depend only on UI filtering.

3. Reuse existing Branch.
4. Reuse existing Child.
5. Reuse existing Enrollment.
6. Reuse existing Teacher/Staff.
7. Reuse existing Activity/Adventure.
8. Reuse existing Attendance.
9. Reuse existing Media/File storage.
10. Reuse existing authorization.
11. Reuse existing audit infrastructure.
12. Do not create duplicate entities.
13. Follow existing naming conventions.
14. Follow existing architectural patterns.
15. Create database migrations.
16. Add validation.
17. Add authorization.
18. Add tests.

Do not rewrite unrelated features.

# 50. Product Principle

The Classroom should answer five questions immediately:

1. **Who is here?**
2. **Who is taking care of them?**
3. **What are we doing today?**
4. **Is the classroom safe and properly staffed?**
5. **What is our classroom becoming over time?**

The final LittleSprouts classroom should therefore combine:

Operational management
+
Child safety
+
Teacher coordination
+
Learning activities
+
Daily routine
+
Memories
+
Classroom identity
+
Classroom growth

The operational information must remain accurate and structured, while the "Living Classroom" experience should make each classroom feel like its own little world.
